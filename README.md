# Boardgame Page

A web application to track board games, share curated game collections, generate visual rule summaries and interactive diagrams/graphs for friends, share formatted game lists and rule cheat-sheets via WhatsApp, and track boardgame events across the UAE.

## Core Capabilities

1. **Game Collection & Play Session Tracker**
   - Catalog owned, wishlist, and played board games with player count, playtime, complexity weight, categories, and mechanics.
   - Log play sessions, scores, winners, and player notes.

2. **Shareable Game Lists**
   - Browse, filter, and share curated lists of games (e.g., by player count, duration, complexity, or game night theme) with friends.

3. **Visual Rule Summaries & Interactive Graphs/Diagrams**
   - Generate clear, readable rule summaries, turn-order flowcharts, setup checklists, and phase/scoring diagrams so players can quickly learn or refresh a game's rules before game night.
   - Interactive analytics and graphs visualizing collection mechanics, complexity distribution, and play history.

4. **WhatsApp Sharing Integration**
   - One-click generation of WhatsApp-ready formatted messages and deep links (`wa.me`) for sharing:
     - Game night candidate lists and collection highlights
     - Quick-reference rule summaries and turn-flow diagrams
     - Upcoming UAE boardgame meetup/event invites

5. **UAE Boardgame Events Tracker**
   - Discover, track, and share boardgame meetups, tournaments, café game nights, and conventions happening across the UAE (Dubai, Abu Dhabi, Sharjah, and beyond).
